# Companion experimental paper (not yet run)

The G-MRT experiment described in Section 6 of the main paper is a separate
study. Nothing in this directory has been executed: no participants, no IRB
approval, no data.

- `platform_design_spec.md` — intended implementation of the two-stage
  randomization, locked evidence bank, and fidelity gate.
- `pilot_preregistration.md` — draft preregistration. It is a design sketch,
  not a registrable document: hypotheses, a power analysis, and the analysis
  model are not yet specified, and the IRB field is a placeholder.

`docs/publication_map.md` records which results belong to which paper.
