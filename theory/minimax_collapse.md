# Minimax Impossibility under Policy Decisiveness (v0.5 — ③의 정리화)

> **지위**: 신규. `formal_framework.md:71`이 "형식적 식별과 실용적 추정가능성은 다르다"고 서술만 하던 것,
> 그리고 `temperature_collapse.md`/위상도가 시뮬레이션으로만 보이던 3국면을 **하한 정리**로 닫는다.
> 이것이 초록의 "no regular estimator escapes the rate" 주장을 정당화하는 근거다 —
> `excursion_bound.md` §5.1이 미해결로 남겨둔 항목.
>
> **범위 주의 (§5)**: 이 정리는 **불가능성(하한)** 이다. 특정 추정량이 *언제 잘 되기 시작하는지*(달성)는
> 다른 질문이며 이 파일이 답하지 않는다. 둘을 하나의 곡선으로 그리면 안 된다.

## 1. 왜 필요한가

`excursion_bound.md`의 Theorem A′는 **고정 π에서의 점근분산**에 대한 진술이다.
π(a|h) > 0이면 V < ∞이고 β는 여전히 regular하게 √n-추정 가능하다. 즉 A′는
"상수가 크다"는 말이지 "불가능하다"는 말이 아니다. 심사자의 첫 질문이 정확히 이것이다:

> "τ > 0이면 √n-추정 가능한데 왜 '한계'라고 부르는가?"

답하려면 π가 n과 함께 날카로워지는 **표류수열** 위에서 minimax 하한을 보여야 한다.
아래가 그것이다.

## 2. 지배량

**정의.** decisiveness D(h) = −log min_{a∈𝒜*} π(a|h) (`excursion_bound.md` Def (D))에 대해

  **M(π) := sup_{d>0} P{D(H) ≥ d}·e^{d}**                                     … (M)

M은 "얼마나 결정적인가"와 "얼마나 자주 그런가"의 최적 절충이다.
Theorem A′의 하한 σ̲²ρ²_min·P(𝓗_d)e^d를 d에 대해 최적화한 것과 같은 양이다.

**주 설계에서의 닫힌형.** H ~ U(−1,1), Δ(H)=H, p_τ=σ(H/τ)이면 D = |H|/τ,
P(D ≥ d) = 1 − dτ이므로 M = sup_u (1−u)e^{u/τ} = **τ·e^{(1−τ)/τ}** (u = 1−τ에서),
즉 log M = 1/τ − 1 − log(1/τ). (위상도의 점선이 이것이다.)

## 3. Theorem C (minimax 하한)

**Theorem C.** 다음 조건의 모형족 𝒫(π, B, σ²)를 생각한다: 행동정책 π는 알려져 있고 고정,
결과는 Y | A=a, H=h ~ N(μ_a(h), σ²), 그리고 |μ| ≤ B. 목표는
β = ψ(q₁) − ψ(q₀) (`excursion_bound.md` §1). 그러면 임의의 추정량 β̂에 대해

  **inf_{β̂} sup_{P ∈ 𝒫} E_P |β̂ − β(P)| ≥ (1/4)·min{ B·ρ_min , ρ_min·σ·√(M(π)/n) }.**   … (C)

특히 표류수열 π_n에 대해 **M(π_n)/n → ∞** 이면 우변은 (1/4)B·ρ_min으로 고정되어
**minimax risk가 0으로 가지 않는다** — 즉 어떤 추정량도, 어떤 rate로도 β를 복원하지 못한다.

*증명 (Le Cam two-point).*
d > 0을 잡고 𝓗_d = {D ≥ d}, c = P(𝓗_d) > 0라 하자. 𝒜*의 최희귀 행동을 a*라 하면
𝓗_d 위에서 π(a*|h) ≤ e^{−d}이다.

두 법 P₀, P₁을 **오직 한 곳에서만** 다르게 둔다:

  μ^{(0)}(a*, h) = 0,  μ^{(1)}(a*, h) = ε   (h ∈ 𝓗_d),   그 외 모든 (a,h)에서 동일.

**(i) 목표 차이.** ψ(q) = E[Σ_a q(a|H)μ(a,H)]이므로
β(P₁) − β(P₀) = E[q(a*|H)·ε·1{H ∈ 𝓗_d}] ≥ ρ_min·c·ε =: Δ.

**(ii) 정보 차이.** 관측 O = (H,A,Y)의 밀도는 P(H)π(A|H)N(Y; μ_A(H), σ²)로 인수분해되고
P₀, P₁은 H-주변분포와 π를 공유한다. 따라서 관측 1개의 KL은 (a*, 𝓗_d) 칸만 기여한다:

  KL(P₀ ‖ P₁) = E_H[ Σ_a π(a|H)·KL(N(μ^{(0)}_a, σ²) ‖ N(μ^{(1)}_a, σ²)) ]
              = c·π(a*|h)·ε²/(2σ²) ≤ c·e^{−d}·ε²/(2σ²).

n개 i.i.d.이면 텐서화로 KL(P₀ⁿ ‖ P₁ⁿ) = n·KL(P₀‖P₁) ≤ n c e^{−d} ε²/(2σ²).

**(iii) ε 선택.** ε을 n·c·e^{−d}·ε²/(2σ²) = 1/2 이 되게 잡으면
ε = σ·√(e^{d}/(n c)). Pinsker에 의해 TV(P₀ⁿ, P₁ⁿ) ≤ √(KL/2) = 1/2.

**(iv) Le Cam.** 두 점 하한 inf sup E|β̂ − β| ≥ (Δ/2)(1 − TV) ≥ Δ/4 이고

  Δ = ρ_min·c·ε = ρ_min·c·σ√(e^d/(nc)) = ρ_min·σ·√(c·e^{d}/n).

d에 대해 상한을 취하면 √(M/n)을 얻는다. |μ| ≤ B 제약 때문에 ε ≤ B로 잘리므로
min{B·ρ_min, ·}가 나온다. ∎

**따름정리 (세 국면).** log M(π_n) − log n → −∞ / O(1) / +∞ 에 따라 하한은
각각 0으로 소멸 / 상수 / B로 포화한다. 세 번째가 위상도의 "편향된 채 안정" 국면이다.

## 4. 수치 검증

**(a) KL 대수.** c=0.4, d=3, ε=0.25, σ²=1: 해석식 6.223e−4 vs MC(8×10⁶) 6.340e−4, 비 1.019. ✓

**(b) 구성의 tightness.** ε을 (iii)대로 잡았을 때 oracle-IPW의 두 법 사이 분리:
d=4에서 **0.96 SD**, d=7에서 **1.07 SD**. 즉 ε\*는 정확히 "간신히 구별 안 되는" 크기다. ✓

**(c) 주 DGP에서의 기만 국면.** continuous_h의 실제 DGP에서 β를 희소처치 영역
(H < −0.6)에서만 이동시킨 두 법:

| τ | n | 참 ATE 격차 | 추정 격차 | 분리 |
|---|---|---|---|---|
| 0.08 | 2,000 | 0.198 | +0.067 | **0.16 SD** |
| 0.08 | 32,000 | 0.200 | +0.134 | **0.40 SD** |
| 0.22 | 2,000 | 0.200 | +0.224 | **1.69 SD** |

τ=0.08에서 n을 16배 늘려도 분리가 0.16 → 0.40 SD에 그친다. τ=0.22에서는 회복된다.
**"편향된 채 안정"은 묘사가 아니라 two-point 구별불가능성이다.** ✓

## 4b. 독립 재검증 (다른 논증 경로)

§4의 검증은 구성 자체를 확인한 것이다. 아래는 **증명의 각 단계를 우회하는** 세 검사이며,
`simulation/src/minimax_crosscheck.py`로 재현된다.

**(i) Pinsker 우회 — TV를 직접 계산.** 증명은 KL → Pinsker → TV ≤ 1/2 경로를 쓴다.
P₀, P₁이 희귀칸에서만 다르므로 우도비는 m ~ Bin(n, ce^{−d})개 관측의 합이고, TV를
그 충분통계량 위에서 직접 MC로 구할 수 있다:

| n | d | Pinsker 상한 | **TV 실측** |
|---|---|---|---|
| 2,000 | 4 | 0.500 | **0.378** |
| 2,000 | 7 | 0.500 | **0.260** |
| 20,000 | 4 | 0.500 | **0.384** |
| 20,000 | 7 | 0.500 | **0.374** |

TV가 Pinsker 상한보다 작으므로 Le Cam 바닥 (Δ/2)(1−TV)는 **진술한 값보다 크다.**
부등식 방향이 맞고, 증명은 보수적이다.

**(ii) 가우시안 특수성 배제.** 결과변수를 Bern(1/2) vs Bern(1/2+ε)로 바꾸고 같은 조건
n·c·e^{−d}·KL = 1/2 을 풀면, 분산을 맞춘 가우시안 대비 ε\* 비가 d=4에서 0.998,
d=7에서 0.967. **ε ~ σ√(e^d/(nc)) 스케일은 정규성이 아니라 매끄러운 족의 국소
KL ≈ ε²/(2σ²)에서 나온다.**

**(iii) Bayes risk — 어떤 추정량도 넘지 못하는 바닥.** two-point prior에 대한
Bayes 추정량(사후평균)의 risk는 minimax risk의 하한이다. 직접 계산하면 진술한
(1/4)√(cM/n)의 **1.59배(d=4), 1.60배(d=7)**. 즉 상수 1/4는 과대하지 않다.

세 검사가 모두 같은 방향을 가리킨다: Theorem C는 유효하고, 진술한 상수는 보수적이다.
**단, 이는 수치 검증이지 증명 검토가 아니다** — Le Cam 두 점 논증의 각 대수 단계는
사람이 확인해야 한다.

## 5. 이 정리가 하지 **않는** 것 — 하한 ≠ 달성

Theorem C는 **언제 불가능한가**를 말한다. **언제 쉬워지는가**는 별개이고, 위상도의
관측 전이는 후자다. 둘의 간격이 분포족에 의존한다는 것을 수치로 확인했다:

| 족 | log E[e^D] − log M | 관측 onset − log M |
|---|---|---|
| U(−1,1) | **1.00** (τ 무관) | 4.71 |
| N(0,1) | **2.06** | 6.96 |

하한(M)과 oracle-IPW의 분산인자(E[e^D]) 사이 간격이 uniform에서 1.00 nat,
normal에서 2.06 nats로 **족마다 다르다**. 그래서 어떤 단일 함수형도 두 곡선을
동시에 예측할 수 없다. 이전에 "평균이냐 꼬리냐"로 후보를 비교한 것은
**잘못 설정된 질문**이었다 — 하한과 달성을 같은 곡선으로 취급했기 때문이다.

**논문에서의 처리**: Theorem C는 붕괴 국면에 대한 정리로 진술하고,
위상도의 관측 전이는 계속 시뮬레이션 소견으로 보고한다. 그림에는 두 선을 그리되
각각이 무엇인지(하한 / n_eff=1 필요조건) 명시하고, 어느 쪽도 전이라고 부르지 않는다.

**남은 열린 문제 (discussion으로)**: 달성 쪽 상계. 즉 β̂_Hájek(또는 AIPW)의
risk에 대한 M·(족 의존 상수) 형태의 상계를 구하면 세 국면이 위아래로 닫힌다.
