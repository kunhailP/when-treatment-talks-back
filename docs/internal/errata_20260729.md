## 검증으로 확정된 오류 (수정 완료)

1. **[이론] "Hájek/IPW가 τ↓0에서 경계 estimand로 수렴" — 틀림.** 수치 반례 확인: τ=0.3, n=4M에서 IPW=1.792≈ATE=1.798 ≠ β^ov=1.356. → Contribution 2를 "overlap collapse + information localization"으로 교체 (framework v0.3, noniden Result A/B). 반례를 논문에 포함하기로.
2. **[코드] 08_policy_entropy.py의 1/p 버그** — rpow(1).rdiv(1) 체인이 항상 1 반환 (n_req가 엔트로피와 무관해짐). 수정 및 재발 방지용 numeric test 필요성 기록.
3. **[시뮬] "fixture 통과" 과장** — 방향 조건 미충족인데 assertion 없이 실행만 됐음. fixture 효과 상향 + --strict assertion 추가, 통과 확인.
4. **[시뮬] ESS 비단조** — 전역-minority Kish가 층별 minority 차이를 뭉갬. 층별 arm-specific 최솟값 + overlap mass로 교체, 단조 붕괴 확인 (0.0014→0.0000).
5. **[해석] "극단 τ의 SD 하락 = 국소화의 유한표본 흔적" — 철회.** 2-상태 DGP엔 연속 결정경계가 없음. 정확한 해석: 희귀 crossover 미관측에 의한 overlap collapse. (temperature_collapse v0.3에 정정 명기)
6. **[동기화] review_packet의 "동기화 완료" 과장** — prereg·platform·taxonomy가 FACT/SOCR로 남아 있었음. 3개 파일 v0.3으로 동기화 완료.
