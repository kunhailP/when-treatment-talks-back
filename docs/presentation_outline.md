## 슬라이드 흐름 (14–16장)

1. **훅 (2장)**: Salvi/Hackenburg — AI가 설득한다. 그런데 *무엇이* 설득하는가?
   메타분석 g=0.02, I²=76% → 분해가 문제. Hackenburg의 최강 지렛대(RM) = 블랙박스 적응 정책.
2. **문제 구조 (2장)**: 처치 = (π, G, E). 로그 분석의 세 실패 —
   support(1A) · 정보 붕괴(A) · 국소화(B). "확률이 0이 아니면 되는 것 아닌가?" 선제 반박.
3. **이론 코어 (3장)**:
   - Result A: V_τ ≥ σ̲²·P(𝓗_δ)·exp(δ/τ) — "추정량을 바꿔도 안 되는" bound 수준 주장
   - **Prop A-T**: 다턴 기하급수 복리 (새 결과 — heuristic 아님)
   - Result B: overlap이 결정경계로 국소화, β^ov는 별도의 (정책 유관) estimand
   - 반례 한 장: 고정 τ에서 IPW target 불변 (1.792≈1.798≠1.356) — 잘못된 직관 차단
4. **핵심 그림 (2장)**: **(n,τ) 위상도** (phase_diagram.png) — 세 국면 + 정확한 경계
   log(1+τ·sinh(1/τ)); battery (continuous_h_battery.png) — oracle OR만 평평(가정으로 산 식별),
   overlap만 자기 target에 안정.
5. **실배치는 어디에 (3장)**: Study 0-b — 3개 모델 전부 엔트로피 중앙값 0, REBT 94.5–98.6%;
   Δ̂/τ 중앙값 = k=20 해상도 상한(측정 자체가 같은 한계에 부딪힘 — 재귀 논점);
   Study 0-c — 56,831 대화, 지시의 dose 설명력 η²=.12–.32. "무작위화된 건 지시였지 행동이 아니다."
6. **처방 (2장)**: G-MRT — 실패↔설계요소 대응표; fidelity gate = 처치커널의 일부, 배정-ITT.
   PA companion 예고 (pilot 80–120).
7. **마무리 (1장)**: 중심 메시지 재진술 + 한계 정직 공개(단일턴 중심 정리는 a fortiori + A-T,
   Study 0은 동기화 지위, 소수 라벨은 인간 코딩 전 유보).

## 예상 질문 대비 (Q&A 카드)

- "IPW/AIPW 쓰면 되잖아" → Result A는 bound 수준 (convolution theorem)
- "그건 OPE에서 알려진 문제" → 4중 경계 (bound 수준 rate · τ-지수화·닫힌형 경계 · 국소화 · 설계 처방)
- "경계 효과가 왜 중요한가" → equipoise/한계 정책 모집단 + 감사 가능성
- "재질의 모델이 원 모델이 아니다" → proxy 지위 명시 + 3계열 재현("structurally frequent") + censoring의 재귀 논점
- "judge 신뢰 가능한가" → κ표 공개, 집계 지표 강건(n_req 비율 0.88–1.52), 인간 코딩 예정
- "T=1 정리로 T=3 주장?" → Remark A′ (a fortiori) + Prop A-T (기하 복리, (M1) 해석 포함)
