# Persuasion Strategy Taxonomy (v0.3 — annotation 전용)

> **용도 한정 (2026-07-29)**: 이 taxonomy는 **Study 0의 기존 대화 annotation 전용**이다. G-MRT 실험의 조작 축은 taxonomy가 아니라 **form(단언/질문) × dose(고/저 정보 패키지)**다 (theory/formal_framework.md §4). 구 버전의 "G-MRT pilot 전략: FACT vs SOCR" 문구는 폐기됨.

| 코드 | 전략 | 정의 | 배제 기준 |
|---|---|---|---|
| FACT | Direct factual correction | 검증가능한 사실·수치를 주장 형태로 제시 | 출처 없는 단정은 CLAIM |
| SOCR | Socratic questioning | 상대 논리의 모순을 드러내는 질문 | 수사적 공격 질문 제외 |
| COMG | Common-ground framing | 공유 가치·정체성에서 출발 | 단순 공감은 EMPA |
| SRCT | Source transparency | 근거의 출처·검증 과정 설명 | |
| EMPA | Emotional appeal / empathy | 감정 인정·공감 | |
| REBT | Counterargument / rebuttal | 상대 주장 직접 반박 | |
| CLAIM | Unsupported assertion | 근거 없는 주장 | |
| META | Meta-conversational | 대화 관리 발화 (분석 제외) | |

- 단위: 시스템 턴, primary/secondary 코딩 · 인간 이중코딩 200턴 κ≥0.6 + 핵심 수치엔 민감도 병기
- form 축과의 대응(참고): FACT/REBT ≈ assertive, SOCR ≈ interrogative — 대응은 근사이며 조작 정의가 아님
